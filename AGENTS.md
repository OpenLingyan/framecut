# Repository Instructions

## Language policy

Use English for all new repository-facing engineering metadata and collaboration, including:

- Branch names.
- Commit subjects and bodies.
- Pull request titles, descriptions, and review comments.
- Issue and discussion titles, descriptions, and comments.
- Release titles, release notes, and changelog entries.
- Code comments, API documentation, and non-localized project documentation.

Localized product strings and explicitly localized documentation may use their target language. For example, `docs/README-zh.md` is intentionally written in Simplified Chinese. Do not translate existing localized user-facing content solely to satisfy this policy.

The automated metadata check enforces ASCII text for branch names, commit messages, pull request titles, and pull request descriptions. Use plain ASCII punctuation in those fields.

## Commit identity

Maintainer commits created from this checkout must use `Franklin <Franklin@creativeapp.cn>`. Never replace the genuine authorship of an external contributor.
