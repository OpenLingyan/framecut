# FrameCut 1.3.0

English and Simplified Chinese interfaces, with a persistent language preference.

## Highlights

- Language packs cover the editor, timeline, export review, errors, menus, accessibility text, and runtime component setup.
- First launch selects Simplified Chinese for Chinese system languages, including Traditional Chinese locales, and English for all other systems.
- The selected language is saved locally and takes precedence on later launches. Existing runtime self-check settings are preserved.
- Open FrameCut > Settings or use Command-comma to choose a language. Changes are saved immediately and apply after quitting and reopening the app, without interrupting the current edit.
- App and DMG packaging verify that both language packs are included and work independently of development build caches.

## Download and install

Download **FrameCut-1.3.0-macOS-universal2-unsigned.dmg** and its matching **.dmg.sha256** file from the release assets. Verify the checksum, open the DMG, and drag **FrameCut** to **Applications**. Launch the installed copy and eject the disk image. A ZIP archive is also available.

```bash
shasum -a 256 -c FrameCut-1.3.0-macOS-universal2-unsigned.dmg.sha256
```

- Requires macOS 14 Sonoma or later. The Universal 2 app includes Apple Silicon and Intel binaries.
- This is an unsigned preview without Apple Developer ID signing or notarization. For an official download you trust, use System Settings > Privacy & Security > Open Anyway after the first blocked launch. Do not disable Gatekeeper.
- Additional media compatibility and content-adaptive compression require FFmpeg. The component wizard guides installation through Homebrew when needed; installation requires internet access.

## Known limitations

- Language changes require an app restart. System-owned dialogs and external component diagnostics are not maintained in FrameCut's language catalogs.
- Managed Macs may prohibit unsigned applications.
- Available codecs depend on the installed FFmpeg build, and compression recommendations remain estimates rather than guarantees of unchanged visual quality.

Videos continue to be processed locally; source videos are never uploaded or modified.
