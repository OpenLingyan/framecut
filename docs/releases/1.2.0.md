# FrameCut 1.2.0

The first public preview of FrameCut, a native macOS video trimming and compression app.

## Download and install

Download **FrameCut-1.2.0-macOS-universal2-unsigned.dmg** and its matching **.dmg.sha256** file from the assets below. Verify the checksum, open the DMG, and drag **FrameCut** to **Applications** in the installer window. Launch the installed app from Applications, then eject the disk image. A ZIP archive and its checksum are also available.

```bash
shasum -a 256 -c FrameCut-1.2.0-macOS-universal2-unsigned.dmg.sha256
```

- Requires **macOS 14 Sonoma or later**.
- One **Universal 2** download supports both Apple Silicon and Intel Macs.
- **Unsigned preview:** this release has no Apple Developer ID signature or Apple notarization. After the first blocked launch, use **System Settings > Privacy & Security > Open Anyway** if you trust this official download. Do not disable Gatekeeper.
- The first-launch wizard checks media components and guides **Homebrew and FFmpeg** installation when needed. Installing those components requires network access; no Python or packaging tools are required on users' Macs.

See the [installation guide](https://github.com/OpenLingyan/framecut/blob/v1.2.0/docs/INSTALLATION.md) for the full procedure and limitations.

## Highlights

- Frame-accurate and keyframe navigation with inclusive In/Out trimming.
- A zoomable thumbnail timeline and local MP4/MOV export.
- Native AVFoundation playback plus FFmpeg compatibility previews for AVI, MKV, WebM, and other media formats.
- Content-adaptive HEVC compression and source-aware export.
- Local video processing: source videos are not uploaded or modified.
- A bilingual drag-to-Applications DMG installer with the FrameCut icon and SHA-256 checksums.

## Known limitations

- macOS warns on first launch because this is not a Developer ID signed or notarized release. Managed Macs may not allow it to open.
- Additional codec support and content-adaptive compression depend on the installed FFmpeg build.
- Compression recommendations are estimates, not guarantees of unchanged visual quality.
